Seu assistente de IA pessoal, direto no Telegram ou no WhatsApp.

Um container, um volume, nenhum painel web. Escolha o modelo, conecte suas ferramentas via MCP e converse pelo app de mensagens que você já usa.

Ver no GitHub Guia de instalação →

Roda sobre o harness do pi.dev. As ferramentas vêm do Composio, do Executor, do Upsy ou do seu próprio gateway MCP.

Instale em quatro linhas e rode o setup 
$ git clone https://github.com/forge-z/pi-bot.git
$ cd pi-bot
$ cp .env.example .env
$ docker compose up -d --build
$ docker compose exec pi-bot npm run setup
Como funciona

O chat de um lado, suas ferramentas do outro

O Pi Bot é um gateway enxuto entre o seu app de mensagens, um modelo de linguagem e as ferramentas que você decide conectar. Não há nada para abrir no navegador: o setup acontece no terminal e todo o resto acontece no chat.

  1. Você manda uma mensagem

    Texto, foto ou mensagem de voz, no Telegram ou no WhatsApp. Um gateway por instalação, escolhido no setup.

  2. Só quem tem permissão entra

    O Telegram aceita os ids numéricos de usuário que você listar. O WhatsApp aceita o número do dono, os números extras que você adicionar e a sua conversa “Você” (a de mensagens para si mesmo). O resto é ignorado.

  3. Seu modelo responde

    O modelo de texto escolhido roda o turno sobre o harness do pi.dev. Um modelo de imagem opcional lê fotos e um modelo de áudio transcreve mensagens de voz.

  4. As ferramentas fazem o trabalho

    E-mail, agenda, busca e mais vêm dos servidores MCP que você conectar. Chamadas que exigem aprovação esperam o seu OK no chat.

Um container, um volume. Configurações, credenciais e conversas ficam em arquivos SQLite no volume Docker montado em /app/data; a imagem em si é somente leitura. O assistente não tem shell, sistema de arquivos nem navegador próprios: tudo o que ele faz fora do chat passa pelas ferramentas que você conectar.

Setup

Pronto em cinco passos, tudo no terminal

O npm run setup é um menu interativo que edita uma seção de cada vez. Enter mantém o valor gravado, segredos ficam ocultos e cada seção vai para o volume quando você escolhe Save and back. O menu é em inglês.

  1. Abra o menu de setup

    Com o container no ar, rode npm run setup dentro dele. Um container novo continua no ar e saudável enquanto espera, e nenhuma variável de ambiente é obrigatória para ele subir.

    O menu principal lista todas as seções: gateway, modelo de texto, modelo de imagem, modelo de áudio e plataforma MCP.

  2. Escolha o gateway

    Em Setup gateway, escolha Telegram ou WhatsApp. É um gateway por instalação: gravar um desliga o outro.

    • Telegram pede o token do bot (oculto enquanto você digita) e os ids numéricos dos usuários que podem falar com ele.
    • WhatsApp continua no próximo passo.

  3. Vincule o WhatsApp (se for o escolhido)

    Informe o número do dono com código do país; números extras são opcionais. Depois, pareie o celular de um destes dois jeitos:

    • Pair with QR — escaneie o QR no WhatsApp, em Dispositivos conectados.
    • Pair with phone code — digite no celular o código que o terminal mostrar.

    A sessão fica gravada no volume e sobrevive a reinícios.

  4. Escolha os modelos

    Text model aceita qualquer provedor oficial do pi-ai (Anthropic, OpenAI, Google, Groq, OpenRouter, xAI, DeepSeek e outros) com chave de API, ou o login do ChatGPT Plus/Pro, sem chave nenhuma.

    Image model e Audio model são opcionais: com eles o bot lê fotos e transcreve mensagens de voz.

  5. Conecte as ferramentas e entre no ar

    Em MCP platform, escolha Composio, Executor, Upsy, um gateway self-hosted, Executor e Composio juntos, ou nenhum.

    Por fim, Save and restart gateway: o bot em execução recarrega a partir do volume, sem rebuild da imagem. Mande um “oi” no chat e um /status para conferir modelo, MCPs e versão.

Funcionalidades

O que o Pi Bot faz hoje

Tudo o que está aqui é descrito no README e está implementado no código.

  • Telegram ou WhatsApp

    Telegram pela Bot API, ou WhatsApp como dispositivo conectado, via QR ou código de pareamento. Um gateway por instalação, com lista de quem pode falar com ele.

  • O modelo que você quiser

    Qualquer provedor oficial do pi-ai com chave de API, ou login do ChatGPT Plus/Pro sem chave. Troque modelo e esforço de raciocínio pelo chat com /model e /thinking.

  • Fotos e mensagens de voz

    Mande uma imagem ou fale em vez de digitar. Um modelo com visão lê as fotos e um modelo de áudio transcreve as mensagens de voz. As respostas são sempre em texto.

  • Tarefas agendadas

    Peça no chat um lembrete único ou uma tarefa recorrente (cron de cinco campos), cada uma com seu próprio fuso horário. A execução fica em silêncio, a menos que tenha algo para avisar. Gerencie tudo com /crons.

  • Ferramentas via MCP

    Conecte Composio, Executor, Upsy (OAuth, sem chave de API) ou qualquer gateway MCP self-hosted. Adicione mais servidores — busca, e-mail, GitHub — com uma pequena lista em JSON.

  • Aprovação antes de agir

    Quando o Executor pausa uma chamada para aprovação, o bot repassa o pedido como um cartão. Uma escrita de resultado incerto nunca é reenviada; quem decide é você, com /resume.

  • Conversas separadas

    /new começa do zero e a conversa anterior continua no volume. No Telegram, cada tópico de fórum tem histórico, modelo e esforço próprios. /compact condensa uma conversa longa.

  • Skills do operador

    Coloque pastas com SKILL.md no volume e liste-as no config.yaml. O modelo pode consultá-las em toda resposta, inclusive nas execuções agendadas.

  • Tarefas de código opcionais

    sandbox_code_task roda tarefas longas de código numa máquina Instabox. Fica desligada até você configurar, a allowlist de repositórios começa vazia, e push ou pull request esperam a sua aprovação.

  • Auto-hospedado e blindado

    Docker Compose com imagem somente leitura, todas as capabilities removidas e healthcheck. Segredos configurados e tokens bearer são mascarados nos logs.

Início rápido

Do zero a um bot funcionando

Você precisa de Docker com Compose e de um token de bot do Telegram ou de uma conta de WhatsApp para vincular. A chave de API do modelo é opcional se você entrar com o ChatGPT.

Shell 
# 1. Baixe o código e suba o container
$ git clone https://github.com/forge-z/pi-bot.git
$ cd pi-bot
$ cp .env.example .env
$ docker compose up -d --build

# 2. Configure gateway, modelos e MCP (interativo)
$ docker compose exec pi-bot npm run setup

# 3. Confira o estado gravado quando quiser
$ docker compose exec pi-bot npm run setup -- --list

O README usa o equivalente docker exec -it <container> npm run setup. Toda variável do .env é um override opcional; deixe em branco e o setup grava tudo no volume. Se o gateway já estiver rodando quando você for parear o WhatsApp, leia o QR em docker compose logs.

FAQ

Perguntas frequentes

Uma instalação pode usar Telegram e WhatsApp ao mesmo tempo?

Não. Cada instalação tem um gateway. Gravar o WhatsApp no setup desliga o Telegram, e vice-versa. Uma instalação que nunca escolheu continua no Telegram.

A conexão com o WhatsApp é oficial?

Não. O gateway do WhatsApp usa o Baileys, que fala o protocolo não oficial do WhatsApp Web e pode levar a restrições na conta. Leve isso em conta ao escolher qual número vincular.

Preciso de chave de API para o modelo?

Não necessariamente. O setup oferece login do ChatGPT Plus/Pro (OAuth) sem chave de API. Para qualquer outro provedor oficial do pi-ai — Anthropic, OpenAI, Google, OpenRouter e outros — você informa a chave desse provedor no setup.

Onde ficam os meus dados?

No volume Docker pi_bot_data, montado em /app/data: configurações, credenciais, conversas e a sessão do WhatsApp. A imagem é somente leitura. O histórico é tão privado quanto esse volume e o servidor onde ele roda.

Ele responde por voz?

Não. Ele entende mensagens de voz quando há um modelo de áudio configurado, mas sempre responde em texto. Uma ferramenta pode gerar um arquivo de áudio, mas a resposta em bolha de voz não está implementada.

Funciona em grupos?

No WhatsApp, grupos, transmissões e canais são ignorados. No Telegram, ids de grupo e de tópico podem ser liberados pela variável de ambiente TELEGRAM_ALLOWED_CHATS, e cada tópico de fórum mantém histórico, modelo e esforço próprios.

Como dou novas habilidades a ele?

Conecte um servidor MCP em vez de mexer no bot. Escolha uma plataforma no setup ou liste servidores extras num arquivo JSON indicado por MCP_CONFIG_FILE. As chaves ficam em variáveis de ambiente, nunca no arquivo. O README sugere serviços para e-mail, busca, scraping, agenda e mais.

Como as tarefas agendadas chegam até mim?

É só pedir no chat — por exemplo, “toda segunda às 9h, me lembre de revisar minhas tarefas pendentes”. O agendamento fica naquela conversa, com fuso horário próprio. Quando roda, ele só manda mensagem se decidir que há algo para avisar.

Já está pronto para produção?

O Pi Bot está em beta: dá para usar no dia a dia, mas configuração e comandos ainda podem mudar entre versões. Faça backup do volume antes de atualizar.
